# CMPSC431 NittanyRide Project

## Project Tech Stack

- Web Framework - FastAPI
- Programming Language - Python
- Development Tool - VSCode
- Database Management System - SQLite

## Deployment

1.  Inside of VSCode, clone this repository
2.  Download and install the package manager uv (https://docs.astral.sh/uv/getting-started/installation/#homebrew)
3.  Install project dependencies by running uv sync
